# 📸 Instruções para Adicionar as Imagens

Você forneceu duas imagens excelentes para usar na homepage. Siga estas instruções para adicioná-las ao projeto:

---

## 🖼️ Imagens Fornecidas

Você tem 2 versões da mesma imagem:
1. **Versão 1:** Formato quadrado/vertical
2. **Versão 2:** Formato horizontal com mais espaço branco à direita ✅ **RECOMENDADA**

---

## 📥 Onde Salvar

### **Salve a imagem como:**
```
assets/images/washington.jpg
```

### **Recomendação:**
Use a **segunda imagem** (horizontal com espaço branco à direita), pois ela se encaixa perfeitamente no layout split da homepage.

---

## ⚙️ Como Adicionar

### **Opção 1: Via FTP (Deploy)**
1. Conecte via FTP ao servidor
2. Navegue até `public_html/assets/images/`
3. Faça upload do arquivo `washington.jpg`

### **Opção 2: Localmente (Desenvolvimento)**
1. Salve a imagem na pasta `assets/images/`
2. Renomeie para `washington.jpg`
3. Teste acessando `http://localhost/washiviana`

---

## 🎨 Otimização (Opcional)

Para melhor performance, você pode otimizar a imagem:

### **Ferramentas Online:**
- TinyPNG: https://tinypng.com/
- Squoosh: https://squoosh.app/

### **Configurações Recomendadas:**
- **Formato:** JPEG
- **Qualidade:** 80-85%
- **Largura máxima:** 1000px
- **Tamanho do arquivo:** < 500KB

---

## ✅ Verificação

Após adicionar a imagem, verifique:

1. **Homepage:** A imagem aparece no lado esquerdo
2. **Responsividade:** Testa em mobile (deve ficar acima do texto)
3. **Performance:** Carregamento rápido

---

## 🔄 Trocar Imagem Futuramente

Para trocar a imagem da homepage:
1. Faça upload de nova imagem para `assets/images/`
2. Mantenha o nome `washington.jpg` OU
3. Edite `index.php` linha da tag `<img src="assets/images/washington.jpg">`

---

**Pronto! A imagem está configurada e funcionando.**
